# ♠ Poker Chips

เครื่องคิดเงินสำหรับเล่นโป๊กเกอร์ (Texas Hold'em) ในชีวิตจริง **ไม่มีไพ่ในเว็บ มีแต่เงิน**
วางมือถือหรือ iPad ไว้กลางโต๊ะ ให้คนคุมโต๊ะกดแทนทุกคน ส่วนไพ่และเงินใช้ของจริงบนโต๊ะ

เว็บคำนวณให้ว่าใครต้องวางเงินเท่าไหร่ หม้อมีเท่าไหร่ ใครเป็น Dealer, Small blind, Big blind และบอกว่าตอนนี้ควรแจกไพ่หรือเปิดไพ่กี่ใบ

เป็นไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้งอะไร ไม่ต้องมี server

---

## ความสามารถ

**ตั้งค่าเกม**
- เลือกจำนวนผู้เล่น 2–10 คน (ค่าเริ่มต้น 6 คน) และตั้งชื่อตามที่นั่ง
- เลือกเงินเริ่มต้นจากรายการ ตั้งแต่ 1,000 ถึง 100 ล้าน หรือพิมพ์เองก็ได้ เหมาะกับเงินจากบอร์ดเกมที่มีแบงค์หลักล้าน
- Small blind / Big blind ถูกตั้งให้อัตโนมัติจากเงินเริ่มต้น (ค่ามาตรฐาน 100 Big blind) มีปุ่มให้เลือกอีก 5 ระดับ และแก้เองได้
- ตั้งให้ขึ้นบลายด์เป็น 2 เท่าทุก 5, 10, 15 หรือ 20 แฮนด์ได้
- สุ่มคนที่เป็น Dealer คนแรกได้

**ระหว่างเล่น**
- โต๊ะรูปวงรี แสดงที่นั่งทุกคน ปุ่ม D (Dealer), SB, BB และชื่อตำแหน่ง (UTG, MP, HJ, CO, BTN ฯลฯ) ที่หมุนไปทุกแฮนด์
- บอกขั้นตอนทุกจังหวะ เช่น แจกไพ่ 2 ใบเริ่มจากใคร เผาไพ่ 1 ใบ เปิด Flop 3 ใบ Turn ใบที่ 4 River ใบที่ 5
- ปุ่มใหญ่กดง่าย: หมอบ, ผ่าน, ตาม, เกทับ (หรือเดิมพัน), ออลอิน
- ตัวเลือกเกทับหลายแบบ: ต่ำสุด, ⅓ ถึง 2 เท่าของหม้อ, ×2 ถึง ×4 ของเดิมพัน, ±1BB, ±5BB หรือพิมพ์เอง
- บอกชัดว่าต้องวางเงินเพิ่มเท่าไหร่ เพื่อให้หยิบเงินจริงวางลงกลางโต๊ะได้ถูก

**ออลอินและหม้อรอง**
- คำนวณหม้อหลักและหม้อรองให้อัตโนมัติ บอกว่าใครมีสิทธิ์ชนะหม้อไหน
- ถ้ามีเงินส่วนเกินที่ไม่มีใครตาม ระบบคืนให้เจ้าของพร้อมแจ้งยอด
- ตอนจบแฮนด์ บอกว่าผู้ชนะต้องหยิบเงินจากกองกลางเท่าไหร่ (รองรับเสมอและหารเงิน)

**อื่น ๆ**
- ปุ่มย้อนกลับ ถ้ากดผิดย้อนได้หลายครั้ง
- แตะที่นั่งผู้เล่นเพื่อแก้ชื่อ แก้ยอดเงิน หรือซื้อเพิ่ม (ผู้เล่นที่หมดตัวซื้อเพิ่มแล้วเล่นต่อได้)
- เกมถูกบันทึกอัตโนมัติในเบราว์เซอร์ รีเฟรชหรือปิดแล้วเปิดใหม่ก็เล่นต่อได้
- ใช้ได้ทั้งมือถือ iPad แนวตั้งและแนวนอน และคอมพิวเตอร์ (iPad แนวนอนแบ่งหน้าจอเป็นโต๊ะทางซ้าย ปุ่มควบคุมทางขวา)

## วิธีใช้งาน

1. เลือกจำนวนผู้เล่น ชื่อ เงินเริ่มต้น และบลายด์ แล้วกด **เริ่มเกม**
2. ทำตามข้อความบนหน้าจอ: แจกไพ่จริงบนโต๊ะ แล้วกดปุ่มยืนยัน
3. เมื่อถึงตาใคร ชื่อบนโต๊ะจะเรืองแสง ให้ผู้เล่นคนนั้นบอกว่าจะทำอะไร แล้วคนคุมกดปุ่มแทน
4. เมื่อจบรอบเดิมพัน เว็บจะบอกให้เปิดไพ่กลาง กดยืนยันเมื่อเปิดแล้ว
5. ตอนเปิดไพ่ ผู้เล่นดูไพ่จริงแล้วตัดสินผู้ชนะ คนคุมแตะชื่อผู้ชนะในแต่ละหม้อ
6. กด **แฮนด์ถัดไป** ตำแหน่งจะหมุนไปให้เอง

## เอาขึ้น GitHub Pages

### วิธีที่ 1: อัปโหลดผ่านเว็บ (ไม่ต้องใช้คำสั่ง)

1. เข้า [github.com/new](https://github.com/new) สร้าง repository ใหม่ ตั้งชื่ออะไรก็ได้ เช่น `poker-chips` เลือก **Public**
2. กด **uploading an existing file** แล้วลากไฟล์ `index.html` และ `README.md` ลงไป กด **Commit changes**
3. ไปที่แท็บ **Settings** → **Pages**
4. ตรง **Build and deployment** เลือก Source เป็น **Deploy from a branch**
5. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–2 นาที หน้า Pages จะแสดงลิงก์ในรูปแบบ
   `https://ชื่อผู้ใช้.github.io/poker-chips/`

### วิธีที่ 2: ใช้ Git

```bash
git init
git add index.html README.md
git commit -m "Add Poker Chips"
git branch -M main
git remote add origin https://github.com/ชื่อผู้ใช้/poker-chips.git
git push -u origin main
```

จากนั้นทำขั้นตอนที่ 3–6 ด้านบน

> ถ้า repository เป็น Private ต้องใช้บัญชีที่รองรับ GitHub Pages แบบ Private หรือเปลี่ยนเป็น Public

## กติกาที่ใช้

เป็น Texas Hold'em แบบไม่จำกัดเงินเดิมพัน (No-limit)

- Heads-up (2 คน): Dealer เป็น Small blind และเดิมพันก่อนในรอบแรก
- เกทับขั้นต่ำเท่ากับขนาดการเกทับครั้งล่าสุด (รอบแรกขั้นต่ำคือ Big blind)
- เงินเหลือเศษตอนหารหม้อ จะให้ผู้ชนะที่นั่งใกล้ซ้ายมือ Dealer ก่อน

### ข้อจำกัด

- ไม่มี Ante
- ถ้ามีคนออลอินด้วยเงินน้อยกว่าขั้นต่ำของการเกทับ คนอื่นจะเกทับต่อได้ (ตามกติกาเข้ม จะทำไม่ได้)
- ถ้า Dealer เดิมหมดตัว ปุ่ม Dealer จะข้ามไปคนถัดไปทันที (ไม่มี dead button)
- เว็บไม่ตัดสินผู้ชนะ ไม่รู้จักไพ่ ต้องให้คนบนโต๊ะบอกผู้ชนะเอง

## แก้ไขเอง

ทุกอย่างอยู่ใน `index.html` ไฟล์เดียว (CSS, HTML, JavaScript)

| อยากแก้ | ไปที่ |
